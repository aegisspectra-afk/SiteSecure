# ניווט שיווקי — SITE SECURE

## Header (נוכחי)

קישורים ישירים בלבד — בלי תפריטים נפתחים:

- מוצר (`/product`)
- פתרונות (`/solutions`)
- מחירון (`/pricing`)
- מחשבון אחסון (`/tools/cctv-storage`)
- כניסה (`/login`)
- CTA ראשי: התחילו בחינם (`/register`)

קישור פעיל: צבע + פס תחתון דק. `hover` ו־`focus-visible` ברורים. גובה header קבוע (`4rem`).

אודות, צור קשר ומרכז ידע — **בפוטר בלבד**.

מרכז ידע מוצג בפוטר וב־sitemap רק אם יש לפחות **3 מאמרים** ב־`KNOWLEDGE_ARTICLES`.

## מובייל (≤768)

המבורגר → תפריט מסך מלא עם אותם קישורים (יעד מגע 48px), CTA בתחתית, סגירה ב־Esc / X, ונעילת גלילה כשהתפריט פתוח.

## RTL / מותג

שמות לטיניים בתוך עברית (`SITE SECURE`, `Aegis Spectra`) עטופים ב־`<bdi>` (רכיב `BrandBdi`).

## תפריט נפתח עתידי (אם יידרש)

לא בשימוש ב־header כרגע. אם חוזרים ל־mega:

1. **טור אחד** בלבד
2. **אייקון Lucide** לכל פריט
3. **כותרת** 15px מודגשת
4. **תיאור** 13px בשורה נפרדת מתחתיה
5. **רוחב קבוע** 320px
6. **מרווח** 8px בין פריטים

הסגנונות לכך שמורים ב־`marketing-enterprise.css` תחת `.mkt-mega*`.
